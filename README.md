# Java Projects

A collection of Java projects, coursework, and programming practice developed throughout my Computing and Information Technology studies at Rochester Institute of Technology (RIT) Dubai.

## About This Repository

This repository contains Java programs and exercises that I have developed while learning and applying different programming concepts.

The code covers everything from basic Java syntax and control flow to object-oriented programming, classes, constructors, inheritance, and more advanced programming concepts.

I use this repository to keep track of my progress as I continue developing my Java programming skills.

## Repository Contents

### Chapter 1

Introductions to the fundamentals of Java programming, including:

* Variables and primitive data types
* Arithmetic and mathematical operations
* Conditional statements
* Input using `Scanner`
* Type casting
* Loops and basic program flow
* Exception handling
* File handling
* Basic Java syntax

### Chapter 2

Programs focused on object-oriented programming concepts, including:

* Classes and objects
* Object creation
* Constructors
* Methods
* Encapsulation

* Creating and working with custom objects

### Chapter 3

More advanced object-oriented programming exercises, including:

* Inheritance
* Parent and child classes
* Method overriding
* Different character classes and behaviours
* Object interaction
* Applying OOP concepts to larger programs

### Chapter 4

Additional Java programming exercises and concepts developed as part of my coursework.

### Java Practice

Additional programs created to practice Java syntax, logic, classes, and problem solving outside of the main chapter exercises.
